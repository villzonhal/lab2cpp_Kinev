## Задача 2.3. Первая треть списка - в конец в обратном порядке

### Текст задачи

Дан список L, количество элементов которого делится на 3. Добавить в конец списка первую треть его исходных элементов в обратном порядке. Использовать один вызов функции-члена `insert`.

**Пример:**
L = [1, 2, 3, 4, 5, 6]
результат: [1, 2, 3, 4, 5, 6, 2, 1]

### Алгоритм решения

1. Находим размер трети: `third = size / 3`.
2. Итератор `third_end` сдвигаем на `third` позиций от начала через `std::advance`.
3. Обратный итератор `first(third_end)` проходит первую треть от конца к началу. Нужный диапазон - `[first, rend())`.
4. Вставляемый диапазон не должен принадлежать самому списку, поэтому сначала копируем его во вспомогательный вектор `reversed`.
5. Одним вызовом `insert(end(), reversed.begin(), reversed.end())` добавляем элементы в конец списка.
6. В `main` ввод повторяется, пока в строке не окажутся только целые числа, количество которых делится на 3 и не меньше 3.

## Задача 3.9. Удаление элементов с чётными номерами в первой половине дека

### Текст задачи

Дан дек D с количеством элементов, кратным 4. Удалить в первой половине исходного дека все элементы с чётными порядковыми номерами (считая, что начальный элемент дека имеет порядковый номер 1). Использовать функцию-член `erase` в цикле с числовым параметром.

*Указание.* Используйте цикл с числовым параметром, повторяющийся N/4 раз (где N - исходный размер дека). Свяжите вспомогательный итератор `i` с началом дека. В цикле выполняйте функцию-член `erase` с параметром, равным `++i`, обязательно присваивая возвращаемое значение итератору `i`.

**Пример:**
D = [1, 2, 3, 4, 5, 6, 7, 8]
результат: [1, 3, 5, 6, 7, 8]

### Алгоритм решения

1. В первой половине `N / 2` элементов, и чётные номера (2, 4, ...) занимают из них ровно `N / 4`. Поэтому `quarter = size / 4` - это количество удалений.
2. Итератор `it` ставим на начало дека.
3. В цикле `quarter` раз выполняем `it = values.erase(++it)`: `++it` указывает на элемент с чётным номером, `erase` удаляет его и возвращает итератор на следующий элемент (с нечётным номером).
4. Присваивание результата `erase` обязательно, потому что удаление из дека делает старые итераторы недействительными.
5. В `main` ввод повторяется, пока количество чисел не станет кратным 4 (и не меньше 4).

## Задача 5.8. Удаление последнего набора из K нулей

### Текст задачи

Дано целое число K (> 0) и вектор V, содержащий только нули и единицы. Удалить в векторе V последний набор из K подряд расположенных нулей (если в этом наборе имеется больше K нулей, то требуется удалить только последние K из них). Если вектор не содержит требуемого набора нулей, то не изменять его. Использовать алгоритм `search_n` и функцию-член `erase`, а также обратные итераторы.

**Пример:**
K = 2, V = [1, 0, 0, 1, 0, 0, 0]
результат: [1, 0, 0, 1, 0]

### Алгоритм решения

1. Вызываем `std::search_n(values.rbegin(), values.rend(), k, 0)`. Поиск идёт с конца, поэтому первый найденный набор из `k` нулей - это последний набор в исходном порядке.
2. Если набор не найден (`run == values.rend()`), функция возвращает `false` и вектор не меняется.
3. Диапазону `[run, run + k)` в обратном порядке соответствует диапазон `[(run + k).base(), run.base())` в прямом. Его удаляем одним вызовом `erase`.
4. Если нулей в наборе больше `k`, удаляются последние `k` из них.
5. В `main` K вводится как одно целое число больше 0, а вектор - как непустой набор только из 0 и 1.
6. По результату функции программа сообщает, был ли набор удалён.

### Текст задачи

Даны списки L1 и L2, у каждого из которых количество элементов делится на 4. В первом списке инвертировать (расположить в обратном порядке) первую половину элементов, во втором списке - вторую половину. Для первого списка использовать алгоритм `swap_ranges` и обратные итераторы, для второго - алгоритм `reverse`. Использовать также функцию `advance`.

**Пример:**
L1 = [1, 2, 3, 4, 5, 6, 7, 8], L2 = [1, 2, 3, 4, 5, 6, 7, 8]

4. Для L2 в функции `ReverseSecondHalf` сдвигаем итератор на `size / 2` через `std::advance` и вызываем `std::reverse(middle, end)`.

## Задача 9.2. Векторы, содержащие все элементы V0

### Текст задачи

Дан вектор V0, целое число N (> 0) и набор векторов V1, …, VN. Известно, что размер вектора V0 не превосходит размера любого из векторов V1, …, VN. Найти количество векторов VI, I = 1, …, N, в которых содержатся все элементы вектора V0 (с учётом их повторений). Использовать алгоритм `includes`, применяя его в цикле к двум мультимножествам (контейнерам типа `multiset`), одно из которых создано на основе вектора V0, а другое на очередной итерации содержит элементы очередного из векторов VI, I = 1, …, N.

5. В `main` вводятся: непустой V0, число N > 0 и N векторов. Размер каждого VI не может быть меньше размера V0, иначе ввод повторяется.

## Задача 10.4. Группировка слов по последней букве

### Текст задачи

Дан вектор V, элементами которого являются английские слова, набранные заглавными буквами. Выполнить группировку элементов вектора V, используя в качестве ключа группировки последнюю букву элемента: в одну группу должны входить все элементы вектора V, оканчивающиеся одной и той же буквой (сгруппированные элементы должны располагаться в порядке, обратном порядку их расположения в исходном векторе). Представить результат группировки в виде мультиотображения M, ключами которого являются ключи группировки, т. е. последние буквы элементов вектора V, а значениями - элементы вектора, оканчивающиеся на соответствующую букву (таким образом, отображение M должно иметь тип `multimap<char, string>`). Вывести полученное отображение (для каждого элемента отображения M вначале выводить ключ, а затем связанный с ним элемент вектора V; ключи могут повторяться). Для перебора элементов контейнеров использовать цикл `for` по элементам контейнера.

**Пример:**
V = [CAT, DOG, BEAT, FROG, ZEBRA]
результат: (A, ZEBRA), (G, FROG), (G, DOG), (T, BEAT), (T, CAT)

### Алгоритм решения

1. Создаём копию вектора слов в обратном порядке: `reversed(words.rbegin(), words.rend())`.
2. В цикле `for` по элементам копии вставляем в `multimap<char, string>` пары `(последняя буква, слово)`: `groups.insert(std::make_pair(word.back(), word))`.
3. `multimap` хранит элементы с равными ключами в порядке вставки, поэтому внутри группы слова идут в порядке, обратном исходному.
4. Результат выводим циклом `for (const auto& entry : groups)`: сначала ключ (`entry.first`), затем слово (`entry.second`).
5. В `main` слова вводятся через пробел, ввод повторяется, пока не появится хотя бы одно слово, состоящее только из заглавных латинских букв `A-Z`.
